# ruralsim

A free, open-source simulation of rural U.S. counties. RuralSim rebuilds counties
in 3D from public data and tests proposed infrastructure before it is built.

- **Five pilot counties:** Chautauqua KS, McDowell WV, Wilcox AL, Thurston NE, Teton ID
- **National table:** 3,144 counties
- **Ten experiments:** pass bars set before each run. 4 met, 5 missed, 1 conditional
  with no pass bar. Every miss is published.
- **Equity rule:** a plan that leaves the worst-off 10% worse off fails.

## Grading
Every result is screening-grade. The engines are reduced-order with assumed
parameters. A result is decision support, not a finding, until full-physics
confirmation.
